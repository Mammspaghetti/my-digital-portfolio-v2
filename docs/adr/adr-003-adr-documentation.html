ADR 3

ADRs are documented as standalone HTML

Status
Accepted

Context

Architecture decisions need to be readable by someone who has not followed the project, such as a recruiter or an engineering manager, without installing anything.

Decision

Each ADR gets its own HTML page in docs/adr/, opened directly in a browser. Pages share adr.css and adr.js and support a dark mode: it follows prefers-color-scheme by default, with a manual toggle remembered in localStorage.

Consequences

  • A new ADR means a new adr-NNN-slug.html file, a link in index.html, and a line in CLAUDE.md.
  • No build step and no dependency: the files work offline.
  • The files live outside src/ and are not part of the Vite bundle. They can be published separately if wanted.
