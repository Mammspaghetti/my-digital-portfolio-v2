ADR 2

React Router with BrowserRouter

Status
Accepted

Context

The site has two pages, Home and Projects, plus a detail view for each project. It will be deployed online, and project URLs should be clean and shareable with recruiters.

Options considered

  • BrowserRouter — clean URLs such as /projects/my-project. Requires the host to serve index.html for unknown paths.
  • Hash routing — works on any static host with no configuration, but URLs look like /#/projects, which is worse for sharing and SEO.

Decision

Use React Router with BrowserRouter.

Consequences

  • The hosting platform must rewrite all paths to index.html (SPA fallback). The exact file depends on the host, for example _redirects on Netlify or vercel.json rewrites on Vercel. The host is not chosen yet.
  • The Vite base option must match the deployment path (default / for a root domain).
  • Page titles and metadata must be set per route, because the HTML is a single shell.
  • Routes are defined in one place under src/app/.
