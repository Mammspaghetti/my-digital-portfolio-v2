ADR 4

Deployment on GitHub Pages

Status
Accepted

Context

ADR 2 requires an SPA fallback and a Vite base matching the deployment path. The code already lives on GitHub, and the site only needs static hosting.

Decision

Deploy dist/ to GitHub Pages with a GitHub Actions workflow (.github/workflows/deploy.yml) on every push to main. The build output is never committed.

Consequences

  • The site is served under /my-digital-portfolio-v2/: Vite base is set to that path and BrowserRouter receives it as basename. The dev server uses the same prefix.
  • GitHub Pages has no rewrite rules: the workflow copies index.html to 404.html so deep links such as /projects still load the app. The response status is 404 for those URLs, which is acceptable for a portfolio but not ideal for SEO.
  • With a custom domain at the root, set base back to /.
  • Pages must be enabled once in the repository settings (Settings → Pages → Source: GitHub Actions).
